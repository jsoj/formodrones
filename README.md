# FormoDrones - Soluções Aéreas Inteligentes & Mapeamento de Precisão

Website moderno e de alta performance desenvolvido para a **FormoDrones**, oferecendo serviços de aerofotogrametria, topografia 3D, inspeção agrícola de precisão e filmagens aéreas 4K em Formosa-GO e região.

## 🚀 Funcionalidades do Site

- **Design System Futurista Dark Mode**: Interface responsiva, com efeito glassmorphism e animações fluidas.
- **Calculadora Interativa de Orçamento**: Simulação em tempo real baseada em hectares e adicionais.
- **Integração Nativa com WhatsApp**: Envio direto de simulações e formulário de contato para atendimento rápido.
- **Showcase de Serviços & Frota de Drones**: Apresentação de equipamentos homologados (DJI Mavic 3 Enterprise, Agras T40, Matrice 300 RTK).
- **FAQ Sanfonado**: Esclarecimento das principais dúvidas regulatórias (ANAC/DECEA) e contratuais.
- **Imagens Exclusivas**: Imagens em alta definição geradas especificamente para a FormoDrones.

## 🛠️ Tecnologias Utilizadas

- **HTML5 & CSS3 Vanilla** (Variáveis HSL, Flexbox, CSS Grid, Glassmorphism, Micro-animações)
- **JavaScript ES6+** (Cálculo em tempo real, animações numéricas, interatividade)
- **Lucide Icons** (Ícones modernos vetorizados)
